# George Music (AppMusic)

Aplicación de reproducción y gestión de música para Android desarrollada con Kotlin y Jetpack Compose.

## Características

- **Jetpack Compose**: Interfaz moderna, reactiva y adaptable.
- **Media3 / ExoPlayer**: Reproducción de audio en segundo plano con soporte de caché y notificación de reproducción.
- **Room Database**: Persistencia local de canciones, listas de reproducción y favoritos.
- **Dagger Hilt**: Inyección de dependencias modular y desacoplada.
- **Arquitectura MVVM**: Separación clara de responsabilidades con ViewModels y repositorios.

## Requisitos y Compilación

- Android Studio Koala / Ladybug o superior
- JDK 17 o superior
- Android SDK mínimo: Android 8.0 (API 26) o superior

```bash
# Compilar el proyecto en modo debug
./gradlew assembleDebug
```
